# Slot-RAE project page

Static project page for *Slot-RAE: Streamlining Object-Centric Learning via Direct Representation Auto-Encoders* (anonymous, under review).

Preview locally:

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

Structure: `index.html` (content), `static/css/style.css`, `static/js/main.js` (gallery tabs, theme toggle, BibTeX copy), `static/images/` (figures from the paper).
To de-anonymize after review: fill in authors/affiliations in the hero, point the Paper button to the paper (replace `<span class="btn disabled">` with `<a class="btn" href="...">`), and update the BibTeX.
